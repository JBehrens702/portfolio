# Design references

- `Reference1.png` — the owner's reference for the top bar (2026-10-09): a solid
  black bar, frozen to the top, with an angled left edge, three orange slashes,
  the logo, and wide square-cut uppercase menu letters.
- `sketch-a-blueprint.html` + `topbar.css` — sketch A ("Blueprint grid"), the
  direction the owner chose on 2026-10-09 out of three sketches: graph paper,
  chamfered (cut-corner) panels, orange headings and corner brackets, a hexagon
  photo, Orbitron + JetBrains Mono (+ Michroma for the menu). Open it from this
  folder; its image paths are relative to the repo.

The owner's direction: retro-futuristic / technical touches, contrasting
colours, a focus on angularity. Purple backgrounds for the highest emphasis,
then black, then white or grey callouts; orange as another colour for headers.
